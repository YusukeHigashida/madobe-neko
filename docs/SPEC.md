# お天気タイムラプス猫（癒し箱庭アプリ）実装依頼

## このファイルについて
Claude Code に渡す実装指示書です。上から順に読んで実装してください。
初心者にも読めるように書いていますが、実装は自由に最適化して構いません。

---

## 1. 何を作るか（結論）

窓辺に座った猫の上を、**一日の天気がゆっくり流れていく「癒しの箱庭」ブラウザアプリ**。
動画ではなく、その場で動くインタラクティブなWebページ。プレゼン（社内のAI活用コンテスト）で見せる想定。

コンセプトは「見ているだけで癒される」。派手さより、あたたかさ・穏やかさ・可愛さを最優先。

### 絶対に外せない要素
- 猫が生きているように動く（呼吸・しっぽ・耳）
- 猫を**なでられる**（マウス/タップに反応する）
- 一日の時間が流れる（朝 → 昼 → 夕方 → 夜）
- 天気の演出（雨・雪）
- 全体があたたかく癒される雰囲気

---

## 2. 技術スタック

- **素の HTML / CSS / JavaScript の1ファイル構成**（`index.html`）を基本にする。
  - ビルド不要、ダブルクリックで開けるのが理想。プレゼン当日に環境依存で動かない事故を避けたい。
  - フレームワーク（React等）は使わなくてよい。使うとしても最終成果物は静的に開ける形にすること。
- 外部ライブラリは基本なしで実装。必要なら CDN 1つ程度まで。
- レスポンシブに軽く対応（PCブラウザで全画面表示が主戦場。スマホでも崩れなければOK）。

---

## 3. 素材（同梱済み）

`assets/` フォルダに入っています。

| ファイル | 内容 | 仕様 |
|---|---|---|
| `assets/cat.png` | 猫（キンカロー、横向き・座り姿、左向き） | **透過PNG（RGBA）** 1376×1143 |
| `assets/bg-day.png` | 背景（窓辺のシーン、昼・晴れ） | RGB 1536×1024（約3:2） |

- 猫は背景が完全に透明。そのまま背景の上に重ねてよい。
- 背景の中の「窓枠（木の棚）」の上に猫を座らせる。左手前に植木鉢があるので、**猫は棚の右寄り〜中央**に配置すると自然。
- 猫は左を向いている＝窓の外を眺める向き。この向きのまま置くこと（反転しない）。
- 猫は大きいので、背景に対して適切なサイズに縮小して配置する（棚に自然に収まる比率に調整）。

---

## 4. レイヤー構造（重要）

奥から手前に、以下の重ね順で組む。CSSの重ね（position + z-index）で実装。

1. **背景レイヤー**：`bg-day.png`
2. **時間帯オーバーレイ**：半透明の色を全面に重ねて朝/夕/夜を表現（後述）
3. **猫レイヤー**：`cat.png`（アニメーションの対象）
4. **天気レイヤー**：雨・雪の粒（コードで描画。canvas か DOM要素）
5. **UIレイヤー**：操作コントロール（最前面）

---

## 5. 機能仕様

### 5-1. 猫のアニメーション（常時）
- **呼吸**：ゆっくり上下 or わずかな拡縮（3〜4秒周期くらい）でふわっと。
- **しっぽ**：ゆらゆら揺れる。※しっぽは画像に含まれているので、画像全体を軽く歪ませる or 揺らす程度でよい。厳密な分離は不要。
- できれば**耳がたまにピクッ**と動くと可愛い（余裕があれば）。
- 動きは全部「やさしく・ゆっくり」。カクカク・素早い動きはNG（癒しが壊れる）。

### 5-2. なでる（インタラクション）
- 猫の上にマウスを乗せる or タップ/ドラッグすると反応する。
- 反応の例（どれか、または組み合わせ）：
  - 目を細める（画像差し替え or 目元にかぶせる簡単な演出）
  - ふるっと気持ちよさそうに揺れる／少し伸びる
  - ハートの小さなエフェクトがふわっと出て消える
  - （音を入れるなら）ゴロゴロ音が小さく鳴る
- 「生々しいアニメ」ではなく「やさしい反応」でよい。癒し重視。

### 5-3. 時間帯（タイムラプス）
- 朝 → 昼 → 夕方 → 夜 をループで自動再生。1周は 30〜60秒くらいの体感でゆっくり。
- 実装は **色オーバーレイ方式** を基本とする（画像は昼1枚しかないため）：
  - 朝：うすいオレンジ〜ピンクを軽く重ねる
  - 昼：オーバーレイなし（そのまま）
  - 夕方：オレンジ〜紫を重ねる
  - 夜：濃紺を重ねる（+ 星をうっすら／窓辺にあたたかい灯り）
- **再生/一時停止ボタン** と、**時間を手動で動かすスライダー**（スクラブ）を用意する。
- 夜になったら猫が少し眠そうになる（目を細める等）と最高。
- ※将来 `bg-morning.png` `bg-sunset.png` `bg-night.png` を差し替えられるように、
  「時間帯ごとに画像を指定できる」作りにしておくと後で本格版に上げやすい（あればそれを使い、無ければ色オーバーレイにフォールバック）。

### 5-4. 天気（切り替え）
- **晴れ / 雨 / 雪** をボタンで切り替えられる。
- 雨：斜めに降る雨粒 + うっすら画面を暗く。雨のときは猫が「毛布にくるまってヌクヌク」風の演出があると◎（無理なら省略可）。
- 雪：ふわふわ舞う雪。
- 雨・雪はすべてコードで生成（画像素材は不要）。

### 5-5. 雲（判断が必要）
- 今の背景は雲が絵に描き込まれているので**そのままでは動かせない**。
- MVPでは**雲は静止でOK**（光と猫が動けば十分癒される）。
- 余裕があれば「うっすら半透明の雲を上に流す」程度の演出を足してもよい（やりすぎ注意）。

---

## 6. UI（コントロール）

画面下 or 端に、目立ちすぎないコントロールをまとめる。

- 再生 / 一時停止（時間）
- 時間スライダー（朝←→夜）
- 天気切り替え（晴れ / 雨 / 雪）
- （任意）音のオン/オフ

デザインは素材の雰囲気に合わせて、木目・やわらかい色・角丸で。UIが世界観を壊さないように控えめに。

---

## 7. あると嬉しい（優先度・低／時間があれば）

- **環境音**：雨音・小鳥のさえずり・猫のゴロゴロ。オン/オフ切り替え付き。癒し効果が跳ね上がる。
- **今日の実際の天気に連動**：大阪の現在の天気を取得して、起動時に晴れ/雨を自動反映。
  - 例：Open-Meteo など**APIキー不要**の無料天気APIが手軽。緯度経度は大阪（約 34.69, 135.50）。
  - 失敗したら晴れにフォールバック。
- **猫の追加ポーズ**：座り / 伸び / 丸まって寝る の画像がもらえたら、時間帯で猫の姿も変える。

## 8. プレゼンでの見え方（意識してほしいこと）

- 審査員は「猫・癒し」が刺さる人。**第一印象の"かわいい・あたたかい"が命**。
- 起動して数秒眺めるだけで「わ、いい…」となる完成度を狙う。
- 操作しなくても勝手に時間が流れて絵になる（＝放置でも成立）。かつ、触ると反応する（＝触ると楽しい）。この両立が理想。

---

## 9. 実装の進め方（おすすめ順）

1. 背景 + 猫を重ねて正しい位置・サイズで表示（静止画として成立させる）
2. 猫に呼吸アニメを付ける
3. 時間帯オーバーレイ + 再生/スライダー
4. なでる反応
5. 雨・雪
6. （余裕があれば）音・天気API・雲

各段階で一度ブラウザで確認しながら進めてください。まず「静止画として綺麗に成立」させるのが最優先です。

---

## 10. 正直な注意点

- 猫（立体的なタッチ）と背景（少しアニメ寄りの平面タッチ）で質感がわずかに違う。並べれば十分馴染むが、気になる場合は猫の周囲にごく淡い影/なじませ処理を入れると座りが良くなる。
- 透過猫の輪郭（毛のフワフワ）は拡大しすぎるとアラが出る。等倍〜縮小の範囲で使う。
- `position: fixed` などで全画面固定するとスクロール事故が起きやすいので、コンテナ基準のレイアウトで組むと安全。
